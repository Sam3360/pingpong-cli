# Pong CLI (fixed)

A real-time Pong game for Windows CMD / PowerShell. No dependencies.

## Run
```cmd
py main.py
```

## Controls
- W / S or ↑ / ↓ — move
- Enter — start / serve / rematch
- Space — pause / resume
- Q — quit

First to 7 points wins. Use a modern terminal and keep the window wide enough to avoid wrapping.
