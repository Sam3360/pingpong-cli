# Pong CLI 🏓

A real-time Pong game for Windows CMD / PowerShell, built with Python's standard library.

## Run

```cmd
py main.py
```

No pip installs required.

## Controls

- **W / S** or **↑ / ↓** — move your paddle
- **Enter** — start / serve / rematch
- **Space** — pause / resume
- **Q** or **Esc** — quit

First to 7 points wins. Paddle hits affect ball angle, and rallies gradually speed up.

> Use Windows Terminal or a modern CMD/PowerShell window for best ANSI rendering. Maximize the terminal if the playfield wraps.
